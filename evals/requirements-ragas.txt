# Phase 4 step 6b -- Ragas judge environment. SEPARATE venv (evals/.venv-ragas),
# on Python 3.13, never installed into the API venv:
#   - Ragas pulls in langchain, datasets, scikit-network, ... none of which the
#     API needs at runtime; keeping them out keeps the API image small.
#   - scikit-network publishes no Python 3.14 wheel (checked on PyPI 2026-09-26),
#     so on the API's 3.14 it would have to compile from source. On 3.13 every
#     package below resolves to a prebuilt macOS arm64 wheel (checked with
#     pip download --only-binary=:all: --python-version 3.13).

# 1.11+ resolves cleanly alongside ragas 0.4.3.
